Questions, answered

What devices does SAGE run on?

SAGE is built with Expo, so the same codebase ships to iOS, Android, and the web. Classroom TV mode is available for a shared screen.

Do I need an internet connection?

An internet connection is needed for sign-in, AI generation, and live multiplayer rooms. Cached lesson content remains viewable offline.

Can educators add their own students?

Yes. Each course has its own roster — educators can share a join code or add students directly from the course page.

Is SAGE free?

The core experience is free for students and educators. Team and school deployments are handled separately.
